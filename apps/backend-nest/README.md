# Muziki Backend

NestJS and PostgreSQL backend for the Muziki marketplace. The listener pays for music; the artist receives their earned share after a validated sale and requests a withdrawal to their registered Mobile Money number.

## Local setup

Copy `.env.example` to `.env`, set `DATABASE_URL` and a long `JWT_SECRET`, then run:

```powershell
.\node_modules\.bin\prisma.CMD generate
.\node_modules\.bin\prisma.CMD db push
.\node_modules\.bin\nest.CMD start --watch
```

## Manual Mobile Money mode

Set only the receiving numbers you own. A payment option without a configured number is unavailable to the listener.

- `DRC_VODACOM_MERCHANT_PHONE`
- `DRC_AIRTEL_MERCHANT_PHONE`
- `DRC_ORANGE_MERCHANT_PHONE`
- `DRC_AFRICELL_MERCHANT_PHONE`
- `MUZIKI_MINIMUM_WITHDRAWAL_CDF` defaults to `20000`

The listener submits a transfer reference. An admin validates it in the mobile admin app, which unlocks the purchase and credits the artist share. The artist does not send money. They request a withdrawal, and the admin sends money manually to the artist's registered payout number before marking the withdrawal paid.

## Render deployment

The root [`render.yaml`](../../render.yaml) creates the API, PostgreSQL database, persistent storage disk, and both web portals. In Render, deploy from the repository root and provide the four Mobile Money numbers as private environment variables. `JWT_SECRET` is generated by Render. Do not configure a fictional phone number.
